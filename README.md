Учебная практика по МДК 02.02. Кострома, 2026.

Разработчики: Столяров А.С., Нечаев А.Д.  

##  Описание проекта
Данный программный модуль предназначен для управления личными заметками. Он позволяет создавать, структурировать с помощью тегов и быстро находить нужную информацию благодаря встроенному механизму полнотекстового поиска.

### Основные возможности:
* **Управление заметками:** создание, просмотр списка и удаление.
* **Тегирование:** привязка ключевых слов (тегов) к заметкам для категоризации.
* **Полнотекстовый поиск:** поиск совпадений по заголовкам и содержимому заметок без учёта регистра.
* **Фильтрация:** быстрый отбор заметок по привязанным тегам.

## 🛠️ Стек технологий
* **Язык программирования:** Python 3.11
* **Библиотека работы с БД (ORM):** SQLAlchemy
* **Драйвер СУБД:** PyMySQL
* **База данных:** MySQL 8.0 (движок InnoDB с поддержкой транзакций и FULLTEXT индексов)
* **Тестирование:** PyTest

## 📂 Структура проекта
* `.github/workflows/ci.yml` — конфигурация автоматического CI-тестирования в облаке.
* `docs/` — папка с отчетной документацией (`kanban.md`, `RELEASE_NOTES.md`, `retrospective.md`).
* `src/` — исходный код бизнес-логики модуля (`database.py`, `models.py`, `manager.py`).
* `tests/` — автоматические тесты для проверки логики версионирования.
* `run_cli.py` — исполняемый файл для запуска текстового меню управления заметками.

## 🚀 Инструкция по локальному запуску

1. Установите необходимые зависимости проекта:
   ```bash
   pip install -r requirements.txt
   ```

2. Убедитесь, что у вас запущен сервер **MySQL** и создана пустая база данных `notes_db` (настройки подключения находятся в файле `src/database.py`).

3. Запустите интерактивное текстовое меню:
   ```bash
   python run_cli.py
   ```

4. Для запуска автоматических Unit-тестов выполните команду:
   ```bash
   pytest
   ```
