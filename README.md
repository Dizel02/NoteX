Учебная практика по МДК 02.02. Кострома, 2026.

Разработчики: Столяров А.С., Нечаев А.Д.  

##  Описание проекта
Данный программный модуль предназначен для управления личными заметками. Он позволяет создавать, структурировать с помощью тегов и быстро находить нужную информацию благодаря встроенному механизму полнотекстового поиска.

### Основные возможности:
* **Управление заметками:** создание, просмотр списка и удаление.
* **Автоматическое версионирование:** при создании заметки в СУБД автоматически сохраняется её начальная версия в таблице истории изменений.
* **Тегирование:** привязка ключевых слов (тегов) к заметкам для категоризации (связь многие-ко-многим).
* **Полнотекстовый поиск:** поиск совпадений по заголовкам и содержимому заметок с помощью нативных индексов MySQL без учёта регистра.
* **Фильтрация:** быстрый отбор заметок по привязанным тегам.

##  Стек технологий
* **Язык программирования:** Python 3.12
* **Библиотека работы с БД (ORM):** SQLAlchemy
* **Драйвер СУБД:** PyMySQL
* **База данных:** MySQL 8.0 (движок InnoDB с поддержкой транзакций и FULLTEXT индексов в XAMPP)
* **Тестирование:** PyTest

##  Структура проекта
* `.github/workflows/ci.yml` — конфигурация автоматического CI-тестирования в облаке GitHub Actions.
* `docs/` — папка с отчетной документацией (`kanban.md`, `RELEASE_NOTES.md`, `retrospective.md`).
* `src/` — исходный код бизнес-логики модуля (`database.py`, `models.py`, `manager.py`).
* `tests/` — автоматические тесты для проверки логики версионирования.
* `run_cli.py` — исполняемый файл для запуска текстового меню управления заметками.

##  Инструкция по локальному запуску

1. Установите необходимые зависимости проекта:
   ```bash
   py -3.12 -m pip install -r requirements.txt
   ```

2. Убедитесь, что в панели XAMPP запущен модуль **MySQL** (настройки автоматического создания базы данных `notes_db` заложены в файле `src/database.py`).

3. Запустите интерактивное текстовое меню программы:
   ```bash
   py -3.12 run_cli.py
   ```

4. Для запуска автоматических Unit-тестов выполните команду:
   ```bash
   pytest
   ```
