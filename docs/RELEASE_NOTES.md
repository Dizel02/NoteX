# Release Notes — Модуль заметок с тегами и полнотекстовым поиском

## [v0.1.0] — 2026-11-05

### Добавлено (Added)
- **Базовый CRUD для заметок:** API-эндпоинты на FastAPI для создания, чтения и обновления заметок.
- **Интеграция с MySQL:** настроено подключение через SQLAlchemy и драйвер PyMySQL.
- **Автоматическое версионирование:** реализована транзакция, которая при любом изменении заметки сохраняет её предыдущее состояние в таблицу `note_versions`.
- **Полнотекстовый индекс:** в базу данных добавлен индекс `FULLTEXT KEY` для поиска по полям `title` и `content`.
- **Полнотекстовый поиск:** создан эндпоинт поиска, использующий конструкцию `MATCH ... AGAINST` в режиме `NATURAL LANGUAGE MODE` с ранжированием результатов по релевантности.

### Изменено (Changed)
- Структура проекта реорганизована: исполняемый код перенесён в директорию `src/`, а тесты — в `tests/`.

### Известные ограничения (Known Issues)
- Поиск по тегам спроектирован на уровне БД, но пока не выведен в эндпоинты API (запланировано на следующий спринт).
