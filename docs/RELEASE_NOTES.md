# Release Notes — Подсистема управления заметками «NoteX»

## [v0.1.0] — 2026-11-09

### Добавлено (Added)
- **Базовый CRUD для заметки «NoteX»:** реализован интерактивный консольный интерфейс (CLI) для создания, просмотра списка и удаления заметок в режиме реального времени.
- **Интеграция с MySQL:** настроено подключение к СУБД через библиотеку SQLAlchemy и драйвер PyMySQL с поддержкой автоматического создания базы данных `notes_db`.
- **Автоматическое версионирование:** реализована транзакция, которая при создании заметки сохраняет её начальное состояние в отдельную таблицу `note_versions`.
- **Полнотекстовый поиск:** создан универсальный поисковый механизм на базе оператора `ILIKE` для быстрого нахождения совпадений по полям `title` и `content` без учёта регистра символов.
- **Архитектурный предохранитель (Fallback):** добавлена логика автоматического переключения на встроенную СУБД SQLite в случае недоступности сервера MySQL (XAMPP) для бесперебойной демонстрации проекта на компьютерах комиссии.

### Изменено (Changed)
- Структура проекта реорганизована: исполняемый код бизнес-логики перенёсён в директорию `src/`, а тесты — в `tests/`.

### Известные ограничения (Known Issues)
- Полнотекстовый поиск по нативному индексу `MATCH ... AGAINST` спроектирован на уровне БД MySQL, но временно перевёдён на универсальный оператор `ILIKE` для обеспечения полной кроссплатформенности модуля при защите через проектор перед комиссией Костромского политехнического колледжа.
